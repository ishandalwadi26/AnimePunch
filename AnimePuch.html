Under the hood

Built to be dropped in.

No framework, no build step, no weight.

One file each

Each control is self-contained. Copy one, ship one.

Zero dependencies

Plain HTML, CSS and JavaScript. Nothing to install or update.

One canvas

All smoke, bursts, splashes and slashes draw on a single canvas over the page.

Motion-safe

Effects switch off entirely when a visitor prefers reduced motion.
